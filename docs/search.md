# 통합검색 · 검색 분석

## 무엇이 검색되나

| 분류 | 대상 | 등록 |
|---|---|---|
| 페이지 | 공개된 페이지 | 코어 |
| 게시글 | 읽을 수 있는 게시판의 공개 글 | brick-board |
| 상품 | 판매중·품절 상품 | brick-shop |

플러그인이 `registerSearchSource` 로 등록합니다. **등록하지 않은 플러그인의
내용은 검색되지 않습니다** ([플러그인 개발](plugin-development.md) 참고).

`GET /api/search?q=<검색어>&scope=<분류>&page=<쪽>`

분류를 지정하지 않으면 전체를 검색하고, 분류별 건수를 함께 줍니다 — 화면이
탭에 "게시글 3" 처럼 표시할 수 있습니다.

## 검색되지 않는 것

권한과 상태에 따라 **볼 수 없는 것은 결과에 나오지 않습니다.**

| 대상 | 이유 |
|---|---|
| 비밀글 | 관리자에게도 보이지 않습니다 |
| 읽기 권한이 부족한 게시판의 글 | 등급으로 판단합니다 |
| 작성 중(`draft`) 상품 | 미공개 상품 노출은 정보 유출입니다 |
| 내린(`hidden`) 상품 | 눌러도 404 입니다 |
| 임시 저장 페이지 | |

> **비밀글은 작성자에게도 검색 결과에 나오지 않습니다.** 자기 글이라도
> 검색 결과에 섞이면, 그 화면을 남에게 보여줄 때 새어 나갑니다.

품절 상품은 **검색됩니다.** 재입고를 기다리는 손님이 있고, "그 상품은 있지만
지금 품절"이라는 정보 자체가 필요합니다.

## 검색어

- **두 글자 이상** — 한 글자는 거의 모든 문서에 걸려 결과가 무의미합니다
- `%` 나 `_` 는 특수문자로 동작하지 않습니다 (그냥 문자로 찾습니다)

## 검색 분석

관리자 → 검색 분석.

### 결과가 없던 검색어 — 가장 먼저 볼 것

손님이 찾았는데 없던 것입니다. 두 가지 중 하나입니다:

1. **정말 없다** — 상품이나 안내를 만들 기회입니다
2. **부르는 이름이 다르다** — 치환 규칙으로 연결하세요

목록의 `연결하기` 를 누르면 치환 규칙 폼으로 이어집니다.

### 인기 검색어

`GET /api/search/popular?days=7&limit=10` — 공개 API 이므로 테마에서 쓸 수
있습니다.

**같은 사람이 하루에 여러 번 검색한 것은 한 번으로 셉니다.** 하지 않으면 한
사람의 반복이 1위가 되고, 그 목록이 화면에 노출됩니다.

**빈손 비율**을 함께 봅니다. 인기 있는데 결과가 없는 것이 가장 먼저 손봐야 할
것입니다.

### 검색어 규칙

**치환** — 다른 검색어로 바꿔 검색합니다.

| 손님이 입력 | 실제로 검색 |
|---|---|
| 아이폰15 | iPhone 15 |
| 우비 | 우산 |

결과에 `replacedFrom` 이 담기므로, 화면이 "'우비'로 검색한 결과를 '우산'으로
찾았습니다"를 보여줄 수 있습니다.

**차단** — 인기 검색어 목록에서만 제외합니다. **검색 자체는 막지 않습니다** —
경쟁사명을 검색하는 손님을 막을 이유가 없습니다. 차단의 목적은 화면에
노출되는 목록을 관리하는 것입니다.

## 기록되는 것과 보관 기간

| 항목 | 저장 |
|---|---|
| 검색어 | 정규화된 형태 + 원문 |
| 결과 수 | 0건 여부가 핵심입니다 |
| 회원 | 로그인했으면 회원 id |
| 접속 IP | **해시로만** |

검색어는 그 자체로 민감할 수 있습니다(질병·법률·재정 문의). 그래서 IP 원본을
남기지 않고, **180일이 지나면 기록을 지웁니다.**

## 플러그인에서 검색 대상 추가하기

```ts
ctx.registerSearchSource({
  label: "문의",
  code: "inquiries",
  order: 20,
  async count({ query, viewer }) {
    // search 와 **같은 조건**을 써야 합니다.
    // 다르면 "37건"이라 표시하고 20건만 보여줍니다.
  },
  async search({ query, viewer, offset, limit }) {
    // 정렬을 고정하세요 — 안 하면 페이지를 넘길 때 같은 항목이 두 번 나옵니다.
    // viewer 로 권한을 거르세요 — 제목만 나와도 내용이 새어 나갑니다.
  },
});
```

`searchExcerpt(본문, 검색어)` 를 쓰면 검색어 주변을 잘라 발췌문을 만듭니다
(HTML 태그도 함께 벗깁니다).

## 자주 겪는 상황

**게시글이 검색되지 않습니다**
brick-board 가 활성화되어 있는지, 그 게시판의 읽기 권한이 검색하는 사람의
등급에 맞는지 확인하세요.

**결과 수가 표시된 것보다 적습니다**
공급자의 `count` 와 `search` 조건이 다릅니다. 플러그인 문제입니다.

**한 분류만 안 나옵니다**
그 공급자가 오류로 실패했을 수 있습니다. 서버 로그에서 `검색 공급자 실패` 를
찾으세요. 하나가 실패해도 나머지는 나옵니다.

**한글 검색이 잘 안 맞습니다**
현재 ILIKE 부분 일치입니다. 조사·어미가 붙은 형태("우산을", "우산에서")는
"우산"으로 찾을 수 있지만, 반대는 안 됩니다. 형태소 분석은 아직 없습니다.
