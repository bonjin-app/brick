# 사업자정보 표시

전자상거래법 제13조는 통신판매업자가 다음을 **소비자가 쉽게 알 수 있도록** 표시하라고
정합니다. 표시하지 않으면 과태료 대상이고, 무엇보다 쇼핑몰을 합법적으로 열 수 없습니다.

> 이 문서는 법률 자문이 아닙니다. 실제 의무 범위는 사업 형태에 따라 다르므로
> 필요하면 전문가의 검토를 받으세요.

---

## 입력

**관리자 → 설정 → 사업자정보**에서 입력합니다.

| 항목 | 쇼핑몰 필수 | 비고 |
|---|:---:|---|
| 상호 | ✅ | 법인명 또는 개인 사업자명 |
| 대표자 | ✅ | |
| 사업자등록번호 | ✅ | **체크섬을 검증합니다** |
| 통신판매업 신고번호 | ✅ | 예: 제2026-서울강남-01234호 |
| 사업장 주소 | ✅ | |
| 전화번호 | ✅ | |
| 이메일 | | |
| 개인정보 보호책임자 | | 개인정보보호법 제31조상 지정·공개 의무 |
| 호스팅 제공자 | | 전자상거래법 시행령상 표시 항목 |

필수 항목이 빠져도 **저장은 됩니다.** 쇼핑몰이 아닌 사이트도 있고, 설치 직후에는
아무 값도 없기 때문입니다. 대신 응답에 `commerceReady: false` 와 빠진 항목이
담겨 관리 화면이 경고합니다.

### 사업자등록번호는 실제로 검증합니다

형식만 보면 오타가 통과합니다. **잘못된 번호를 표시하는 것은 표시하지 않는 것과
같은 문제**라서 국세청 체크섬 규칙을 검증합니다.

```
가중치 [1,3,7,1,3,7,1,3,5] 를 앞 9자리에 곱해 더하고
9번째 자리 곱(digit×5)의 십의 자리를 추가로 더한 뒤
(10 - 합%10) % 10 이 마지막 자리와 같아야 한다
```

하이픈은 있어도 없어도 되고, 저장할 때 `000-00-00000` 형태로 맞춰줍니다.
`000-00-00000` 은 체크섬을 통과하지만(합이 0) **칸만 채우는 것**이라 거부합니다.

## 표시

기본 테마는 **푸터에 자동으로** 렌더합니다. 값이 없는 항목은 아예 내려오지 않아
"대표자: " 같은 빈 라벨이 남지 않고, 하나도 없으면 영역 자체가 사라집니다.

### 테마를 직접 만든다면

렌더 컨텍스트의 `site.business` 를 씁니다. 값이 없으면 `null` 입니다.

```html
{{#if site.business}}
<div class="brick-business">
  {{#if site.business.companyName}}<span>상호 <b>{{ site.business.companyName }}</b></span>{{/if}}
  {{#if site.business.businessNo}}<span>사업자등록번호 {{ site.business.businessNo }}</span>{{/if}}
  {{#if site.business.mailOrderNo}}<span>통신판매업신고 {{ site.business.mailOrderNo }}</span>{{/if}}
  ...
</div>
{{/if}}
```

각 항목을 `{{#if}}` 로 감싸세요 — 값이 없는 항목은 컨텍스트에 없으므로
감싸지 않으면 라벨만 남습니다.

### 별도 페이지로 만들려면

`GET /api/business-info` 는 **인증 없이** 조회됩니다. 관리자만 볼 수 있으면
"소비자가 쉽게 알 수 있도록"이 성립하지 않기 때문입니다.

```json
{
  "info": { "companyName": "...", "businessNo": "220-81-62517", ... },
  "labels": { "businessNo": "사업자등록번호", ... },
  "commerceReady": true,
  "missing": []
}
```

`labels` 를 함께 주므로 화면이 항목 이름을 따로 관리하지 않아도 됩니다.

## 왜 코어에 있는가

| 위치 | 문제 |
|---|---|
| 테마 설정 | 테마를 바꿀 때마다 다시 입력하게 되고, 빠뜨립니다 |
| 쇼핑몰 플러그인 | 플러그인을 끄면 **법적 표시가 사라집니다** |
| **코어 사이트 설정** | ✅ |

값은 사이트가 갖고, 테마는 렌더만 합니다 (ADR-45).

---

## 검증

```bash
DATABASE_URL=postgresql://... bash scripts/smoke-storefront.sh
```

사업자정보 관련 항목이 특히 확인하는 것:

- 공개 조회가 되는가 (관리자만 보면 표시 의무가 아니다)
- 체크섬이 틀린 번호가 거부되는가
- 테마 푸터에 **실제로** 렌더되는가
- 빈 항목의 라벨이 남지 않는가
