# 카카오 알림톡 (알리고)

한국 쇼핑몰의 주문·배송 안내는 문자보다 카카오 알림톡이 기본입니다 — 문자보다 싸고 잘 읽힙니다.
Brick 은 **문자·알림톡 (알리고)** 확장으로 알림톡을 보냅니다.

알림톡은 **카카오가 미리 검수한 템플릿과 글자 하나까지 같아야** 나갑니다. `#{변수}` 자리만 바뀔
수 있습니다. 그래서 Brick 은 본문을 그대로 보내지 않고, 운영자가 **알림마다 승인된 템플릿을
연결**하면 그 템플릿의 변수를 채워 보냅니다.

## 켜는 법

1. 알리고에서 카카오 채널을 연결하고 **발신프로필 키**를 받습니다 (알리고 → 카카오톡 → 채널 연결)
2. 알리고에서 템플릿을 만들어 검수를 받습니다 (아래 변수 이름을 그대로 쓰세요)
3. 관리자 → 플러그인 → **문자·알림톡 (알리고)** 활성화
4. 관리자 → **문자 발송**: 아이디 · API 키 · 발신번호 · **알림톡 사용** · **발신프로필 키**
5. 관리자 → **알림톡 템플릿**: 알림마다 템플릿을 고릅니다 (검수를 통과한 것만 나옵니다)
6. 쇼핑몰 설정의 **주문 안내를 문자·알림톡으로도 보낸다** 를 켭니다

## 연결할 때 확인하는 것

- 템플릿 **원문은 알리고에서 받습니다** — 손으로 옮겨 적으면 한 글자만 틀려도 발송이 거절됩니다.
- **검수(APR) 전이거나 카카오가 중지한** 템플릿은 연결할 수 없습니다.
- 템플릿에 **그 알림이 채울 수 없는 변수**가 있으면 거절하고, 쓸 수 있는 변수를 알려 줍니다.
  (연결해 두면 발송할 때마다 거절되어 조용히 문자로만 나가게 됩니다.)
- 템플릿을 알리고에서 고쳐 다시 검수받았다면, 연결을 한 번 다시 저장해 새 원문을 받으세요.

## 나가는 규칙

| 상황 | 결과 |
|---|---|
| 템플릿을 연결한 알림 | 알림톡 |
| 연결하지 않은 알림 | 문자 (문자 사용이 켜져 있을 때) |
| 손님에게 카카오톡이 없다 | 대체 문자 — **문자 사용이 켜져 있을 때만** (대체 문자도 요금이 나갑니다) |
| 알림톡 요청 자체가 거절됨(포인트 부족·템플릿 중지 등) | 문자로 한 번 (문자 사용이 켜져 있을 때) |

이메일을 비우고 전화번호만 적은 비회원 손님도 안내를 받습니다.

## 쇼핑몰 주문 알림의 변수

| 알림 | 변수 |
|---|---|
| 주문 — 접수 | 공통 + `#{입금계좌}` `#{입금기한}` (무통장입금일 때만 값이 있습니다) |
| 주문 — 결제 확인 | 공통 |
| 주문 — 발송 | 공통 + `#{송장번호}` |
| 주문 — 운송장 번호 등록 | 공통 + `#{송장번호}` |
| 주문 — 취소 | 공통 |
| 주문 — 환불 완료 | 공통 |

공통: `#{고객명}` `#{주문번호}` `#{상품명}`(여러 개면 "외 N건") `#{결제금액}` `#{쇼핑몰명}`
`#{주문조회}`(주문 조회 주소 — 비회원은 조회 토큰 포함. 버튼 링크에 쓰세요)

예시 템플릿:

```
[#{쇼핑몰명}] #{고객명}님, 주문(#{주문번호})이 접수되었습니다.
상품: #{상품명}
금액: #{결제금액}
입금계좌: #{입금계좌}
```

버튼: 웹링크 `주문 조회` — 모바일·PC 링크 모두 `#{주문조회}`

## 플러그인 개발자

알림을 보내는 플러그인은 알림 종류와 변수를 선언하고, 보낼 때 값을 넘깁니다.

```ts
ctx.registerNotificationEvent({
  event: "shop.order.paid",
  label: "주문 — 결제 확인",
  vars: [{ name: "주문번호", description: "주문번호", sample: "20260924-000001" }],
});

await ctx.notify({ kind: "shop.order", event: "shop.order.paid", vars: { 주문번호 }, title, body, phone, sms: true });
```

알림톡 확장은 이 목록을 관리 화면에 보여 주고, 연결된 템플릿이 없으면 `title`·`body` 로 문자를
보냅니다. 발송기는 `SmsMessage.event`·`vars` 로 같은 값을 받습니다.
