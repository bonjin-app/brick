# 로드맵

목표는 하나입니다. **그누보드5 + 영카트5로 하던 일을 Brick에서 다 할 수 있게 하는 것.**

"더 좋은 기술"은 목표가 아닙니다. 그누보드로 사이트를 운영하던 사람이 Brick으로
옮겨왔을 때 *없어서 못 하는 일*이 없어야 합니다. 그래서 이 문서는 자랑이 아니라
**격차 목록**입니다.

## M15 — 회원 생애주기 (법적 필수) ✅ 완료

**왜 최우선인가.** 회원 탈퇴가 없는 사이트는 한국에서 **운영할 수 없습니다.**
정보통신망법은 이용자가 언제든 동의를 철회할 수 있어야 한다고 정하고,
개인정보보호법 제21조는 목적 달성 후 지체 없는 파기를 요구합니다.
가입 시 약관·개인정보 수집 동의도 마찬가지입니다. 이건 기능이 아니라 **전제**입니다.

- **약관 동의** — 이용약관 · 개인정보 수집·이용 동의(필수), 마케팅 수신(선택).
  관리자가 본문을 편집하고, 개정 시 재동의를 받는다. 동의 이력을 남긴다
  (분쟁 시 "동의받았다"를 증명해야 하는 쪽은 사업자다).
- **만 14세 미만 가입 제한** — 법정대리인 동의 절차 없이는 가입을 막는다.
- **이메일 인증** — 가입 후 인증 메일, 미인증 상태의 권한 제한을 관리자가 선택.
- **회원 탈퇴** — 즉시 탈퇴. 개인정보는 파기하고, 전자상거래법상 보존 의무가 있는
  주문·결제 기록은 **작성자를 끊고 남긴다**(5년). 게시글은 남길지 지울지 선택.
- **내 정보 수정** — 비밀번호 변경(현재 비밀번호 확인), 닉네임, 연락처, 수신 동의.
- **휴면 계정** — 장기 미접속 계정 처리. 파기 전 사전 통지.

## M16 — 사이트 운영 기본기 ✅ 완료

그누보드 사이트가 예외 없이 다 쓰는 것들입니다.

- ~~**1:1 문의**~~ ✅ — 비공개 문의 + 관리자 답변 + 대화 이어가기, 비회원 문의(조회
  비밀번호), 담당자 지정, 답변 메일 알림. 남의 문의는 **404** 로 응답한다 —
  403 은 "그 문의가 존재한다"를 알려주고 문의번호는 순차적이라 열거할 수 있다.
- ~~**FAQ**~~ ✅ — 분류 + 검색 + 조회수 + "도움이 되었나". `<details>` 로 만들어
  JS 없이 접히고 검색엔진은 답변을 다 읽는다.
- ~~**설문조사**~~ ✅ 복수 선택 · 기간 · 기타 의견. IP를 **해시로만** 저장해 중복
  투표를 막고(완벽하지 않음 — 공유기 아래는 한 표로 묶인다), 결과 공개 시점을
  고를 수 있다. 숨길 때는 득표 수를 응답에 넣지 않는다 (ADR-48).
- ~~**최신글 모아보기**~~ ✅ — 여러 게시판을 나란히. 게시판 수만큼 쿼리하지 않고
  윈도우 함수로 한 번에 가져온다(메인은 가장 많이 열리는 화면이다).
- ~~**회원 단체메일**~~ ✅ — 조건으로 회원을 골라 발송. 종류(공지/광고)를 고르면
  **수신자 조건·`(광고)` 표기·수신거부 링크가 자동으로 결정된다** — "광고를 동의
  없이 보내기"를 표현할 방법을 두지 않았다(ADR-50). 발송 직전에 동의를 다시
  확인해 그 사이 철회한 사람을 건너뛴다. 수신거부는 **로그인 없이** 링크 한 번.
  검증은 SMTP 스텁을 띄워 **받은 메일을 직접 읽는다** — 대상 쿼리만 보면
  제목의 `(광고)`가 빠져도 통과한다.
- ~~**robots.txt · sitemap.xml**~~ ✅ — 플러그인이 자기 URL을 제공하는 레지스트리
  방식(ADR-40). 조각으로 나눠 십만 건 규모에서도 메모리가 터지지 않는다.
  비밀글·비공개 게시판·임시 상품은 제외된다.

## M17 — 쇼핑몰 실무 (거의 완료)

~~지금 쇼핑몰은 "팔 수는 있지만 사후 처리를 못 하는" 상태입니다.~~
사후 처리(취소·반품·교환)가 들어갔습니다. 남은 것은 편의 기능과 표시 의무입니다.

- ~~**주문 취소 · 반품 · 교환**~~ ✅ 상품 단위 부분 처리, 할인 안분 환불,
  청약철회 7일(전자상거래법 제17조), 사유별 반송비 부담(불량은 사업자 — 고객에게
  청구하면 위법), 수거·입고 단계. 물건을 받기 전에는 환불되지 않는다 (ADR-44).
- ~~**위시리스트 · 최근 본 상품**~~ ✅ 비회원도 사용하고 로그인 시 이어받는다
  (ADR-46). 담아둔 뒤 품절되면 표시한다.
- ~~**지역별 배송비**~~ ✅ 우편번호 구간으로 판단한다 (ADR-47) — 주소 문자열로는
  "제주도청"과 "제주식당"을 구분할 수 없다. 무료배송이어도 지역비는 붙는다.
- ~~**사업자정보 표기**~~ ✅ 코어 설정 + 테마 자동 렌더. **사업자등록번호 체크섬을
  실제로 검증**한다 (ADR-45) — 잘못된 번호를 표시하는 것은 표시하지 않는 것과 같다.
- **관련 상품 · 함께 구매** — 상품 상세 하단.
- **판매 리포트** — 기간별 · 상품별 · 분류별. 지금 통계는 총액 수준이다.

## M18 — 그누보드·영카트에서 옮겨오기 ✅ 완료

**채택의 실질적 관문.** 아무리 좋아도 10년 쌓인 게시글을 버릴 수는 없습니다.

- ~~MySQL 접속 정보를 받아~~ → **덤프 파일**로 읽는다 (ADR-42). 공유 호스팅은
  MySQL 외부 접속을 막으므로 원격 접속을 전제하면 "안 되는 사람"이 대부분이 된다.
- ~~비밀번호 보존~~ ✅ bcrypt(`$2y$`) · 구형 MD5 · sha256 을 그대로 저장하고
  첫 로그인 성공 시 argon2 로 승급한다 (ADR-43). 회원은 아무것도 하지 않는다.
- ~~레벨 매핑~~ ✅ 경계를 조정할 수 있고 리허설이 결과를 먼저 보여준다.
- ~~리허설 모드~~ ✅ 아무것도 쓰지 않고 보고한다. 옮기지 않는 것도 목록으로.
- ~~영카트 상품·주문 이전~~ ✅ 분류 계층 복원(ca_id 앞자리가 부모), 조합형 옵션을
  한 줄로 펼침, 주문 상태 매핑(알 수 없는 값은 입금대기 — 임의로 완료로 보면
  매출이 부풀려진다), 금액 불일치는 할인으로 흡수, **과거 주문이 재고를 줄이지 않음**.
- **남은 것: 게시글·상품 본문의 첨부 이미지 주소 변환** (지금은 리버스 프록시로 연결).

## 의도적으로 안 하는 것

- **워드프레스식 자체 업데이터** — Node는 모듈을 메모리에 유지하므로 파일 부분 교체가
  복구 불가 상태를 만들 수 있다. 원자적 교체(새 디렉터리 → 검증 → 심볼릭 링크 전환)로
  설계하지 않을 거라면 넣지 않는다. ([docs/upgrade.md](upgrade.md))
- **그누보드의 10단 회원 레벨** — 플러그인끼리 레벨 숫자의 의미를 합의할 수 없다.
  4단 역할(guest/member/manager/admin)로 접는다. (ADR-25)
- **순수 PHP 호스팅 지원** — Node 런타임이 필요하다. 물리적으로 불가능하다.

## 진행 방식

각 단계는 **E2E 스모크로 검증되어야 완료**입니다. 화면이 뜨는 것과 동작하는 것은
다르고, 특히 돈·개인정보·권한이 걸린 경로는 항목으로 못박아 둡니다.
현재 1,342개 항목이 실제 PostgreSQL과 실제 서버 프로세스로 돕니다.
