# 쪽지 (brick-memo)

회원 간 쪽지입니다. 포인트가 설치되어 있으면 발송 비용을 매길 수 있습니다.

## 시작하기

1. 관리자 → 플러그인 → **쪽지** 활성화
2. 관리자 → 페이지 → 새 페이지
   - 주소(slug): **`memo`**
   - 블록: **쪽지함** 추가
   - 발행

이것으로 다섯 화면이 동작합니다:

| 주소 | 화면 |
|---|---|
| `/memo` | 받은 쪽지함 |
| `/memo/sent` | 보낸 쪽지함 |
| `/memo/write` | 쪽지 쓰기 (수신자 자동완성) |
| `/memo/blocks` | 차단 목록 |
| `/memo/<쪽지id>` | 읽기 |

헤더에 안읽은 개수를 표시하려면 **쪽지 알림** 블록을 테마나 페이지에 배치하세요.

## 기능

| 영역 | 내용 |
|---|---|
| 발송 | 이름·이메일 자동완성으로 수신자 선택 |
| 받은함/보낸함 | 읽음 여부 표시, 안읽은 개수 배지 |
| 각자 삭제 | 받는 사람이 지워도 보낸함에는 남습니다 |
| 차단 | 차단한 회원의 쪽지를 받지 않습니다. **단방향** |
| 도배 방지 | 같은 사람에게 재발송 간격, 하루 발송 한도 |
| 포인트 | 발송 시 차감 (0이면 무료) |
| 답장 | 받은 쪽지에서 바로 답장 |

## 설계에서 중요한 것

### 프라이버시 — 관리자도 내용을 볼 수 없다

쪽지는 회원 간 사적 대화입니다. 그래서:

- **당사자(발신자·수신자)만** 내용을 열람할 수 있습니다. 관리자도 403입니다.
- 관리자 목록은 **누가 누구에게 언제 얼마나** 보냈는지만 보여줍니다 —
  스팸 대응에는 그 정보로 충분하고, 내용을 읽을 이유가 없습니다.
- **본문을 서버 렌더에 담지 않습니다.** 껍데기만 서버가 내고 내용은 인증된 API 요청으로만
  가져옵니다. HTML에 박아 두면 캐시·프록시·브라우저 이력에 남을 위험이 커집니다.
- 수신자 검색은 **이메일을 마스킹**합니다 (`u1*@example.com`) — 검색으로 회원 이메일이
  수집되지 않게 합니다.

### 각자 삭제

삭제 플래그를 발신자·수신자에게 따로 둡니다. 받는 사람이 지워도 보낸 사람의 보낸함에는
남습니다. **둘 다 지웠을 때만** 실제로 제거합니다 — 보관할 이유가 없어지는 시점입니다.

### 포인트 차감의 원자성

발송 비용이 설정되어 있으면, 포인트 차감과 쪽지 저장이 **하나의 트랜잭션**입니다.
차감만 되고 쪽지가 안 가면 사용자가 손해를 봅니다.

포인트가 부족하면 400으로 실패하고 **쪽지도 저장되지 않습니다.**

정책은 비용 차감인데 포인트 플러그인이 꺼져 있으면 **503으로 명확히 실패**합니다.
조용히 무료로 보내면 정책이 무력화되기 때문입니다.

### 차단은 단방향

A가 B를 차단하면 B는 A에게 보낼 수 없지만, A는 B에게 보낼 수 있습니다.
차단은 "받지 않겠다"는 의사이지 "대화 금지"가 아닙니다.

차단당한 쪽에는 "차단되었다"고 알리지 않고 중립적인 메시지로 거절합니다 —
차단 사실 자체가 정보이기 때문입니다.

## API

`/api/plugins/brick-memo` 아래입니다. 모두 로그인이 필요합니다.

| 메서드 | 경로 | 설명 |
|---|---|---|
| GET | `/inbox?page=` | 받은함 (안읽은 개수 포함) |
| GET | `/sent?page=` | 보낸함 |
| GET | `/unread-count` | 안읽은 개수 (배지용) |
| GET | `/:id` | 읽기 (받은 쪽지면 읽음 처리) |
| POST | `/` | 발송 (`receiverId` 또는 `receiverEmail`) |
| DELETE | `/:id` | 삭제 (내 쪽에서만) |
| POST | `/read-all` | 전체 읽음 처리 |
| GET | `/cost` | 발송 비용 안내 |
| GET | `/recipients/search?q=` | 수신자 검색 (이메일 마스킹) |
| GET | `/blocks/list` | 차단 목록 |
| POST/DELETE | `/blocks/:userId` | 차단 / 해제 |

### 관리자 (manager 이상)

`/admin/messages` (목록·삭제, **내용 제외**), `/admin/settings-list` (정책)

## 훅

| 훅 | 시점 |
|---|---|
| `memo.sent` | 발송 후 — `{ memoId, senderId, receiverId }` |

알림 발송(메일·푸시)을 붙이려면 이 훅을 구독하세요.

## 스크랩

쪽지와 함께 **스크랩**(게시글 북마크)이 게시판에 추가되었습니다.

| 메서드 | 경로 | 설명 |
|---|---|---|
| POST | `/api/plugins/brick-board/posts/:id/scrap` | 토글 (누르면 등록, 다시 누르면 해제) |
| GET | `/api/plugins/brick-board/my/scraps` | 내 스크랩 목록 |

글 상세 화면에 스크랩 버튼이 나타납니다. 읽을 수 있는 글만 스크랩할 수 있습니다.
